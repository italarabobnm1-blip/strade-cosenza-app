# Strade Provinciali — Provincia di Cosenza

App mobile per consultare i tracciati delle strade provinciali (S.P.), i cippi chilometrici, i tratti di competenza e le segnalazioni di manutenzione — pensata per cantonieri, capocantoniere e ditte.

Dati sorgente: file KML esportati da Google Earth.

Per aggiornare i dati dopo aver modificato/aggiunto un KML, eseguire `genera_app.py` nella cartella dei KML sorgente e ripubblicare questo file.
